A Delphi unit containing procedures and functions for minimizing your program to the system tray (notification area).
This unit also includes the definition of a class TkuForm — a form with property CloseToTray: when the [x] button in the form's head is clicked, the application is minimized to the system tray.
	
Модуль Delphi содержащий процедуры и функции для сворачивания вашей программы в трей(область уведомлений).
Также этот модуль содержит описание класса TkuForm – это форма имеющая свойство CloseToTray: при нажатии кнопки [x] в заголовке такой формы, приложение сворачивается в трей.
